Frequently Asked Questions

Bagaimana cara mendapatkan API Key?

Register akuhun gratis di Hamzz Cloud, lalu buat API Key dari dashboard. API Key bisa langsung digunakan untuk upload file.

Apakah file aman disimpan?

Ya, file disimpan di server terenkripsi. Link file unik dan tidak bisa ditebak. Fitur expired memastikan file otomatis terhapus.

Bisa untuk bot WhatsApp?

Ya! API kami compatible dengan semua platform. Contoh integrasi dengan Baileys, whatsapp-web.js, dan Python tersedia di dokumentasi.

Apakah ada garansi uptime?

Untuk plan Pro dan Enterprise, kami memberikan garansi uptime 99.9%. Free tier best effort.

Bisa upgrade atau downgrade?

Ya, Anda bisa upgrade/downgrade kapan saja dari dashboard. Penyesuaian billing akan diprorata.

Bagaimana cara menghapus file?

File otomatis terhapus saat expired. Anda juga bisa menghapus manual dari dashboard atau via API DELETE /file/:id.
