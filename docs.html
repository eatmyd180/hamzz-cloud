API Documentation

Integrasikan layanan upload file ke aplikasi Anda dengan mudah

Base URL: https://hamzz-cloud.vercel.app/api\

Authentication

Semua endpoint memerlukan API Key yang dapat diperoleh dari dashboard setelah registrasi.

Headers:
  x-api-key: hk_your_api_key_here

Atau menggunakan query parameter:

https://hamzz-cloud.vercel.app/api/upload\?api_key\=hk_your_api_key_here\\

Endpoints

POST /upload

Upload file ke cloud storage Hamzz Cloud.

📋 Parameters (multipart/form-data)

FieldTypeRequiredDescription
fileFileYesFile yang akan diupload (max 50MB)
expiryStringNo5m, 1d, 7d, 30d, never (default: never)

📝 Example Request (cURL)

curl -X POST https://hamzz-cloud.vercel.app/api/upload \
  -H "x-api-key: hk_xxx" \
  -F "file=@/path/to/image.png" \
  -F "expiry=7d"

✅ Example Response

{
  "success": true,
  "fileId": "67a3f2b8c4d5e6f7a8b9c0d1",
  "url": "/api/file/67a3f2b8c4d5e6f7a8b9c0d1",
  "fullUrl": "https://hamzz-cloud.vercel.app/api/file/67a3f2b8c4d5e6f7a8b9c0d1",
  "expiry": "7d",
  "expiryMessage": "File akan expired dalam 7 hari",
  "remainingQuota": 95
}
GET /file/:id

Mengambil file berdasarkan ID. Endpoint ini bersifat public.

📝 Example Request

GET https://hamzz-cloud.vercel.app/api/file/67a3f2b8c4d5e6f7a8b9c0d1\\
                
Response: Returns the file content with appropriate Content-Type header.
GET /files

Mendapatkan daftar semua file yang diupload menggunakan API key yang sama.

📝 Example Request

curl -X GET https://hamzz-cloud.vercel.app/api/files \
  -H "x-api-key: hk_xxx"

Integration Examples

Node.js / JavaScript
import fs from 'fs';
import FormData from 'form-data';

const API_KEY = 'hk_your_api_key';
const formData = new FormData();
formData.append('file', fs.createReadStream('./image.png'));
formData.append('expiry', '7d');

const response = await fetch('https://hamzz-cloud.vercel.app/api/upload', {
  method: 'POST',
  headers: { 'x-api-key': API_KEY },
  body: formData
});

const data = await response.json();
console.log('Uploaded URL:', data.fullUrl);
Python
import requests

API_KEY = "hk_your_api_key"
url = "https://hamzz-cloud.vercel.app/api/upload"

with open("image.png", "rb") as f:
    files = {"file": f}
    data = {"expiry": "7d"}
    headers = {"x-api-key": API_KEY}
    response = requests.post(url, files=files, data=data, headers=headers)

print(response.json()["fullUrl"])
WhatsApp Bot (Baileys)
async function handleMediaMessage(msg) {
  const media = await msg.downloadMedia();
  const formData = new FormData();
  formData.append('file', Buffer.from(media.data, 'base64'), media.filename);
  
  const response = await fetch('https://hamzz-cloud.vercel.app/api/upload', {
    method: 'POST',
    headers: { 'x-api-key': process.env.HAMZZ_API_KEY },
    body: formData
  });
  
  const result = await response.json();
  await msg.reply(`✅ File uploaded!\n🔗 ${result.fullUrl}`);
}
