API Documentation

Integrasikan layanan upload file ke aplikasi Anda dengan mudah

Base URL: https://hamzz-cloud.vercel.app/api\\

Authentication

Semua endpoint memerlukan API Key dari dashboard.

Headers:\n  x-api-key: hk_your_api_key_here

Endpoints

POST/upload

Upload file ke cloud storage.

curl -X POST https://hamzz-cloud.vercel.app/api/upload -H "x-api-key: hk_xxx" -F "file=@image.png"
GET/file/:id

Mengambil file berdasarkan ID.

GET https://hamzz-cloud.vercel.app/api/file/67a3f2b8c4d5e6f7a8b9c0d1\\\\\
